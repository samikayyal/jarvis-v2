# Jarvis OAuth branding site

These static files are the public home and privacy pages for the private Jarvis
Google OAuth app. Google Auth Platform branding in the `jarvis-kurtz` project
points to `https://jarvis.samikayyal.com/` and
`https://jarvis.samikayyal.com/privacy/`.

Cloudflare Pages project: `jarvis-samikayyal`. It was created with Direct Upload,
so editing these source files does **not** update the live site. To publish an
approved change, upload the contents of this directory to that Pages project and
verify both public URLs. Keep OAuth credentials out of this directory and the
deployment archive.

The privacy page is a public statement about production data handling. Review
its claims against the active runtime before publishing an update.
