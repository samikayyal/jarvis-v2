Privacy policy

Jarvis is a private personal assistant operated by Sami Kayyal for his own use. This policy explains how Jarvis handles data from its connected Google account. There is no public account registration.

Google data Jarvis accesses

With the account owner's authorization, Jarvis can read Gmail messages, read and export Drive files, and read Calendar events. It can send or reply to Gmail messages and create or update Calendar events only after the owner approves the exact action. Jarvis does not change Drive files.

How the data is used

Jarvis uses Google data to carry out the owner's requests, such as finding an email, summarizing a document, or checking a calendar. Relevant content and tool results may be sent to OpenAI to generate a response. Jarvis does not sell Google data or use it for advertising.

Storage and protection

OAuth credentials are kept in a protected configuration file on the private Jarvis server. Working conversation context is held in memory and cleared when the session ends or the service restarts. Private runtime traces can contain message text, Google tool results, and responses. Those traces rotate by size and may remain on the server or in backups; Jarvis does not promise automatic deletion after a fixed period. WhatsApp transport and message storage are handled by the separate OpenWA gateway.

Revocation and deletion

The account owner can revoke Jarvis's Google access from their Google Account connections. To request deletion of locally retained Jarvis data, email kayyal.sami@gmail.com. Revoking Google access does not itself remove existing local traces or backups.
